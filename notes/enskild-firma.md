# Enskild firma

Krav och frågor att utreda:

- Ny kund företag skall vara Verksamhet inklusive Enskild Firma.
- Kundnamn skall kunna ändras om det är enskild firma.
- För Individ: varna vid kreditupplysning. Idag sker det bara ...
- Personen bakom enskild firma skall läggas till vid enskild firma som kontakt. Görs i Common Service av Martin.
- KYC-frågor skall kunna markeras för alla typer av bolag / individ.
- Samma sak för riskfrågorna.
- När man lägger till enskild firma skall alla sekundära enskilda firmor listas i Basic Info. Informationen skall hämtas från CreditSafe.
- Den primära enskilda firman är den som väljs; sekundära enskilda firmor skall hanteras som (sälj)projekt på den primära enskilda firman.
- Fråga om kreditupplysning även för privatpersoner.

Blockerande fråga:

- Dessa saker blockas av Company Type som inte är introducerat ännu på samma sätt som i Planner (eller så är det de). Verifiera.
